# Changelog

All notable changes to Crosshair X Alternative are documented here. Versions follow semantic versioning.

## [1.0.0] — 2026-11-21

### Added

- External crosshair overlay with dot, cross, ring and T shapes.
- Live editor: gap, length, thickness, colour and outline update without a restart.
- Five colour swatches and a custom preset slot.
- Per-game profiles: the last crosshair used for a game is restored when you switch back.
- Hotkeys to toggle the overlay, cycle presets and nudge its position.
- Portable settings file stored beside the application; no registry writes, no installer.
- Landing page with a single manual download action and an archive password shown next to a copy button.

### Notes

- First public build. All presets and settings are local.
- Designed for borderless windowed and windowed games. Exclusive fullscreen may cover the overlay.
