## Overview

Crosshair X is a paid overlay. This is the free, portable alternative: a small Windows app that draws a custom crosshair above your game, with a live editor, per-game profiles and hotkeys.

Track the shape you actually aim with. Dot, cross, ring and T presets ship with the build; gap, length, thickness, colour and outline are yours to adjust while the preview updates. Each game can keep its own crosshair, and one key hides the overlay when you need a clean screen.

If you have been searching for *crosshair x alternative*, *free crosshair overlay* or *custom crosshair generator*, this is the tool that answers all three in one window — and it does not ask for a subscription, an account or a game installation.

## How it works

1. **Download from the landing page.** Open [the landing page](https://dawnknighttruss28.github.io/crosshair-x-alternative/) and use the download button there. The current build, version notes and unpacking instructions live on that page, so it is the only place worth bookmarking.

3. **Pick a shape and a hotkey.** The preview updates as you drag. Bind one key to hide the overlay and one to cycle presets.
4. **Start your game in borderless windowed mode.** The overlay is a transparent always-on-top window, so it sits above the game instead of inside it.

## Safety notice

This tool does not touch any game files. It runs as a separate transparent window and never reads, modifies or injects anything into a game process.

- It does not require the game, a launcher or an account.
- It does not install a driver, a service or a background updater.
- It does not send your presets anywhere; the configuration file stays on your disk.
- Uninstall is deleting the folder.

Overlay rules differ between games and tournaments. Some competitive titles and event organisers restrict third-party overlays, so check the policy that applies to you before using the tool there.
